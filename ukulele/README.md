# 갈림길 우쿨렐레 노트

음표 텍스트를 적으면 오선보와 우쿨렐레 TAB을 함께 그려 주고, 브라우저에서 바로 재생하는 한 장짜리 페이지입니다.

- `index.html`: 그대로 열거나 정적 호스팅에 올리면 되는 완성본
- `page.html`: Artifact 게시용 원본(문서 머리 없이 본문만). `index.html`은 이 파일을 감싸서 만듭니다.

기능: 오선보 + TAB 자동 생성, 운지 자동 선택, 재생/템포/조옮김/반복, 메트로놈, 코드 반주와 운지표, Low-G 튜닝, 지판을 눌러 음 찾기와 입력.

처음 열면 입력 방법을 보여 주는 연습용 예시가 나옵니다. 갈림길의 실제 멜로디는 들어 있지 않습니다.
